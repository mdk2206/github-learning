\# Kali Linux Setup



\## Overview



Kali Linux is used as the security testing machine in the SOC lab.



It is used to generate controlled security traffic against the

Windows and Ubuntu Web systems.



\## Role



Kali is used for:



\- Network testing

\- Web reconnaissance

\- HTTP request generation

\- Security testing

\- Detection validation
